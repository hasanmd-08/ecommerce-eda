# 🛒 Exploratory Data Analysis of an E-commerce Dataset

An Exploratory Data Analysis (EDA) project focused on understanding customer purchasing behavior, sales trends, and business insights using Python and data visualization techniques.

## 📌 Overview

This project explores an e-commerce dataset to identify meaningful patterns in customer transactions and purchasing behavior. The analysis includes data cleaning, statistical summaries, feature exploration, and visualizations to uncover insights that can support business decision-making.

The project covers:
- Data cleaning
- Data exploration
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Data visualization
- Business insights

---

## 🎯 Objective

- Perform comprehensive Exploratory Data Analysis.
- Clean and preprocess the dataset.
- Identify customer purchasing trends.
- Analyze relationships between variables.
- Visualize important business metrics.
- Generate actionable business insights.
